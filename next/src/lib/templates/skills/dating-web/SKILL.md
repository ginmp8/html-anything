# Community and Matching Dashboard
Use an approachable consumer product aesthetic with editorial typography and restrained highlights.
- Provide a left navigation rail, a signal ticker containing only real supplied activity, and headline KPI cards.
- Show a 30-day mutual matches bar chart only if daily data is provided.
- Add a match-rate trend panel with an explicit denominator, period and missing-data state.
- Use accessible labels and legible charts; do not invent members, activity, matches or dates.
- Keep the layout responsive and distinguish a static snapshot from truly live data.
