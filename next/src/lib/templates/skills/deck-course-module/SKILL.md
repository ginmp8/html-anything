# Course Module Deck
Build an educational deck with a warm-paper ground and Playfair-style serif headings.
- Start with a module cover naming the topic and instructor when provided.
- Keep explicit learning objectives visible in a left sidebar through the lesson.
- Organize concept slides with explanations and grounded examples.
- Include a multiple-choice knowledge check with clearly selectable answers where appropriate; do not invent unprovided facts as assessments.
- Close with a recap and preview of the next module when a continuation is known.
- Content determines slide count and depth; ensure clear reading order and keyboard navigation.
