# Direction-Key Minimal Keynote
Designed for talks with a strong message and few supporting visuals.
- Let the user's outline determine slide count; reuse layouts rather than imposing a fixed eight-slide cap.
- Each slide uses one solid background selected from indigo, cream, burgundy, emerald, gray, purple, white or charcoal.
- Use exceptionally large display headings (up to about 160px where space allows), a short 4px accent rule and monospace arrow-led lists.
- Show left/right key hints in the lower-left corner and a slide number at lower right.
- Implement working keyboard navigation with hash synchronization. Maintain legibility and contrast in every palette.
