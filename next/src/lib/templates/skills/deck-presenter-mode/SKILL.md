# Presenter Mode Deck
For talks where the speaker needs an integrated script and rehearsal controls.
- Provide speaker notes in an aside.notes element on each slide, ideally about 150–300 words when the source supports that much content.
- Add a compact lower-right toolbar: T cycles through five coherent themes; S opens a dedicated teleprompter popup.
- Teleprompter layout shows CURRENT, NEXT, SCRIPT and TIMER panels with working state updates.
- Default theme is Tokyo Night, with a usable light alternative among the themes.
- Ensure keyboard navigation, focus states and readable speaker notes; do not fabricate speech text when none was supplied.
